## How to add a trigger

1. Identify the phrase or event that should trigger behavior
2. Define the concrete action (shell command, file load, question, workflow)
3. Link to the source memory that explains why this trigger exists
4. Keep the table under 20 entries — triggers are reflexes, not an encyclopedia
